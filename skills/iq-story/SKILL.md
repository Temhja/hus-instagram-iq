# iq-story

Reels bring strangers; Stories turn followers into conversations. In Iraq the
conversation ends on WhatsApp, so every sequence is built to start a DM.

## Before writing

Read `voice.md` and `plan.md` for the brand. Ask what actually happened today
(shoot, client delivery, studio session, a mistake, a delivery). A story
sequence without a real event is filler.

## The sequence (3–6 frames)

```
F1  HOOK       motion + one line. The first frame decides if they tap through.
F2  CONTEXT    what's happening, filmed, not designed.
F3  INTERACT   one sticker with a job (below).
F4  PROOF      a result, a client reaction, a before/after (cleared only).
F5  ASK        one action: reply with a word / DM / link / WhatsApp.
```

## Stickers by job

| job | sticker | example |
| --- | --- | --- |
| warm the algorithm | poll (2 options) | أي تصميم أحسن؟ ١ ولا ٢ |
| find buyers | question box | شنو أكثر شي يوقفك تسوي إعلان؟ |
| teach + test | quiz | شگد لازم ميزانية أول حملة؟ |
| measure desire | slider | شگد تحب تجرب هالشي؟ |
| launch / event | countdown | افتتاح الاستوديو الخميس |
| send traffic | link | only when the destination is ready and on mobile |

**Every poll / question reply is a DM opener.** Reply to voters with a
specific, short message (via /iq-engage), not a pitch.

## DM → WhatsApp funnel

1. Story ask → user replies with a word or answers the question box.
2. First DM: answer the actual question in one line + one question back.
3. When there's buying intent (سعر، موعد، شلون أطلب): move to WhatsApp with
   the number and a one-line reason ("أدزلك النماذج والأسعار هناك").
4. Never paste prices that aren't confirmed by the brand.

## Rules

- Film over design. Talking-head and over-the-shoulder beats templates.
- Text on frames: ≤ 10 words, right-aligned, inside the safe zone (keep the
  top ~250px and bottom ~340px clear on 1080×1920; approximations, check on a
  phone).
- Mourning periods (Muharram/Ashura, Arbaeen): no music trends, no
  celebratory stickers; check the brand's stance.
- Highlights: after the sequence, say which highlight it belongs to
  (الأسعار، الأعمال، آراء الزبائن، شلون نشتغل).

## Output

Frame-by-frame list: frame, what's on screen, text, sticker, and the reply
template for anyone who engages. End with the highlight it goes into.
